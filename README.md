# Chess Clock

Beautiful chess clock for over-the-board play. 12 time controls, increment support, tap to switch.

**Category:** Brain Training  
**Live:** [chessclock.freeappstore.online](https://chessclock.freeappstore.online)

## Development

```bash
pnpm install
pnpm dev
```

## Deploy

Push to main — auto-deploys to R2 via GitHub Actions.
